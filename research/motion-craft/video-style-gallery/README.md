# Video-style gallery

The video styles the direction step offers: each one played on the same 10 s strip (hook, product card, number, agent, close), so only the look changes. Open `index.html` to browse them by canvas and mood. Each folder holds `style.json` (the definition the direction step reads), `frame.html`, `preview.mp4` and `poster.jpg`. Fonts and their licences: `_fonts/LICENCES.md`.
