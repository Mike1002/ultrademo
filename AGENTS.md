# Ultrademo (for coding agents)

This repository makes product videos. The workspace is `scaffold/`; run every command from there.

- First time on this machine: `cd scaffold && npm run setup` (ask the user first; it installs packages and two browsers).
- Your playbook: [`scaffold/.claude/skills/ultrademo/SKILL.md`](scaffold/.claude/skills/ultrademo/SKILL.md). Read it fully and follow it whenever the user asks for a product video, including its section for agents other than Claude Code.
- Keys go in `scaffold/.env`, typed there by the user. Never ask for one in the chat.
